# 简历项目代码骨架

这些代码用于面试复习和二次开发，不代表原简历项目的完整源代码。编译前请按实际芯片引脚、CubeMX 生成的 `main.h`、OpenCV 模型和数据库配置修改。

## 目录

- `http_server/`：Linux C++17、非阻塞 socket、`epoll`、线程池、HTTP/1.1 GET、静态文件服务。
- `balance_car/`：STM32 控制循环、编码器、姿态融合、串级 PID 和 PWM 输出骨架。
- `smart_fan/`：DHT11、红外按键、PWM、OLED 和自动/手动状态机骨架。
- `face_qt/`：Qt + OpenCV 多线程采集/检测/识别的最小示例。

## 面试时的边界

请把“自己真正实现过”的部分和“参考/待完善”的部分分开说明；不要把示例中的吞吐量、准确率或硬件引脚当成真实项目数据。
